ChatNest 

ChatNest is a full-stack AI chatbot web application that lets users interact with an AI, manage conversations, upload documents, and get information through web search.

Features
AI-powered chat using Google Gemini
User authentication
Conversation history
AI memory
Document upload and processing
Web search
Multiple AI personas
Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
AI: Google Gemini API
Authentication: JWT, bcrypt
